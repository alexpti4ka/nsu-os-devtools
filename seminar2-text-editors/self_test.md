Всего 7 вопросов — по одному на каждую тему семинара: относительные пути, установка локального пакета, оценка дискового пространства, раздельное перенаправление потоков, просмотр больших файлов, конвейеры обработки текста и `sed`.

## 1. Относительные пути

> В папке проекта на рядом лежат два каталога: `reports` и `incoming`. Сейчас вы находитесь в `reports`. Какой относительный путь указывает на файл `data.txt` в каталоге `incoming`?

- **А.** `incoming/data.txt`
- **Б.** `../incoming/data.txt`
- **В.** `../../incoming/data.txt`
- **Г.** `reports/incoming/data.txt`

## 2. Установка локального пакета

> Вам передали локальный пакет `tool.deb`. Какой командой можно установить его и позволить пакетному менеджеру загрузить недостающие зависимости?

- **А.** `sudo dpkg -i tool.deb`
- **Б.** `sudo apt update`
- **В.** `dpkg -L tool`
- **Г.** `sudo apt install ./tool.deb`

## 3. Дисковое пространство

> Нужно узнать, сколько места занимает каталог проекта, и сколько свободного места осталось на его файловой системе. Какие команды подходят для этих двух задач соответственно?

- **А.** `du` и `df`
- **Б.** `df` и `du`
- **В.** `file` и `stat`
- **Г.** `find` и `ls`

## 4. Раздельное перенаправление потоков

> Программа `generator` пишет события в `stdout`, а диагностику — в `stderr`. Нужно добавить их в два уже существующих журнала, сохранив старые записи. Какая команда подходит?

- **А.** `generator 1> events.log 2> errors.log`
- **Б.** `generator 1>> errors.log 2>> events.log`
- **В.** `generator 1>> events.log 2>> errors.log`
- **Г.** `generator >> events.log 2>&1`

---

## 5. Просмотр больших файлов

> Нужно открыть длинный журнал, листать его вперёд и назад и искать нужные записи внутри файла. Какой инструмент лучше подходит?

- **А.** `cat`
- **Б.** `less`
- **В.** `wc`
- **Г.** `head`

## 6. Конвейер обработки текста

> Записи журнала имеют формат:

```text
timestamp|level|source|file|status
```

> Что выведет конвейер?

```bash
cut -d '|' -f 3 events.log | sort | uniq -c
```

- **А.** Общее количество записей в журнале
- **Б.** Все уровни сообщений и количество записей каждого уровня
- **В.** Только источники, у которых встречались ошибки
- **Г.** Все источники и количество записей от каждого источника

## 7. Замена в файле через `sed`

> В файле `service.conf` есть строка `log_level=debug`. Что произойдёт после выполнения команды?

```bash
sed 's/debug/info/' service.conf > service-active.conf
```

- **А.** В новый файл попадёт конфигурация с `log_level=info`, а исходный файл останется прежним
- **Б.** В исходном файле `debug` заменится на `info`, а новый файл не появится
- **В.** Замена произойдёт и в исходном, и в новом файле
- **Г.** В новый файл попадёт только строка `log_level=info`, остальные строки будут отброшены

---

## Ответы

| № | Ответ | Пояснение |
|:-:|:-----:|-----------|
| 1 | **Б** | `..` поднимает вас на уровень вверх — в корень проекта, где и лежит соседний каталог `incoming`. Вариант `../../incoming/data.txt` ушёл бы на два уровня выше. |
| 2 | **Г** | `apt install ./tool.deb` устанавливает локальный файл и сразу докачивает зависимости. `dpkg -i` не разрешает зависимости — после неё обычно требуется `apt install -f`. |
| 3 | **А** | `du` считает размер каталога и его содержимого, а `df` показывает состояние файловой системы и свободное место на ней. |
| 4 | **В** | Оба потока пишутся через `>>`, поэтому старые записи сохраняются, а явные `1>>` и `2>>` разводят `stdout` и `stderr` по разным файлам. |
| 5 | **Б** | `less` листает файл вверх и вниз и умеет искать по нему; `cat` выводит всё сразу, `head` — только начало, `wc` считает строки и байты. |
| 6 | **Г** | При разделении по `|` третий столбец — это `source`. `sort` группирует одинаковые значения рядом, а `uniq -c` считает, сколько раз каждое из них встретилось. |
| 7 | **А** | `sed` без ключа `-i` только печатает результат в `stdout`, а `>` сохраняет этот вывод в новый файл. Исходный `service.conf` не изменяется. |
