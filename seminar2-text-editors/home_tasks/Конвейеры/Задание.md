# Домашнее задание. Конвейеры: дело кофейни «Байт»

Вы устроились администратором в небольшую кофейню «Байт». Хозяйка, Марина, оставила вам четыре файла и записку: «Разберись, что у нас происходит. Касса в последние дни не сходится, гости жалуются, склад пустеет. Отчитайся в пятницу!»

Работать нужно в терминале, только командами из курса. Исходные файлы не изменяйте: все результаты сохраняйте в новые файлы через `>`.

Ответы на вопросы вида «Объясните...», «Почему...» записывайте по мере работы в `results/answers.txt` — они входят в артефакт работы (см. раздел «Проверка и сдача работы»).

Задания идут от простых к сложному, выполняйте их по порядку.

> **Правило каждого задания:** сначала соберите конвейер по одному звену, глядя на вывод после каждого `|`. Так проще понять, где что сломалось.

## Материалы

| Файл | Что внутри | Разделитель |
|---|---|---|
| `orders.log` | журнал заказов за три дня (72 строки) | `\|` |
| `reviews.txt` | отзывы гостей (16 строк) | обычный текст |
| `staff.txt` | сотрудники (7 строк) | `:` |
| `stock.csv` | остатки на складе (первая строка — заголовок) | `,` |

Формат строки `orders.log`:

```text
дата|время|бариста|напиток|размер|цена|оплата
2026-10-08|08:02:12|misha|cappuccino|M|250|card
```

| Поле | Пример | Значение |
|---|---|---|
| дата | `2026-10-08` | день заказа |
| время | `08:02:12` | время заказа |
| бариста | `misha` | кто принял заказ |
| напиток | `cappuccino` | что заказали |
| размер | `M` | размер напитка (`S`, `M`, `L`) |
| цена | `250` | цена в рублях (`0` — бесплатно) |
| оплата | `card` | способ оплаты (`card`, `cash`, `app`, `none`) |

Формат `staff.txt`: `логин:роль:смена:телефон`, например `kostya:barista:morning:+7-900-111-02-02`.

Формат `stock.csv`: `item,qty,unit,supplier` (позиция, количество, единица, поставщик).

### Инструменты

`cat`, `head`, `tail`, `wc`, `grep`, `cut`, `sort`, `uniq`, `sed`, `echo`, `man`, а также `|`, `>`, `>>`.

Нужные ключи ищите в документации. Каталог результатов создаётся один раз в начале работы.

## Проверка и сдача работы

### Артефакт

Работа сдаётся одним архивом. Его готовит проверяющий скрипт, но убедитесь, что каталог `results/` содержит все файлы:

| Файл | Из какой задачи |
|---|---|
| `lines.txt` | задача 1 |
| `orders-21-25.txt` | задача 1 |
| `wifi-reviews.txt` | задача 2 |
| `top-drinks.txt` | задача 4 |
| `staff-new.txt` | задача 6 |
| `shopping.txt` | задача 8 |
| `hours.txt` | задача 9 |
| `report.txt` | задача 10 |
| `answers.txt` | письменные ответы на вопросы «Объясните...» из всех задач |
| `session.txt` | запись терминальной сессии (`script`) |

Если вы прерывали запись сессии и снова запускали `script -a results/session.txt`, ничего страшного: флаг `-a` дописывает данные в тот же файл.

### Как проверить работу

Из каталога задания выполните:

```bash
chmod +x check.sh
./check.sh
```

Скрипт проверит состав `results/`, ключевые ответы и исходные файлы, напечатает результаты проверок и, если всё в порядке, соберёт архив `s2-coffee.tar.gz`. Можно приложить скриншот этого вывода.

### Как передать работу

Отправьте файл `s2-coffee.tar.gz` своему семинаристу удобным способом — канал связи уточните на занятии (например, телеграм или почта). В теме сообщения укажите: `s2-coffee — ФИО`.
