# Подготовка к семинару: установка Ubuntu на компьютер

> Актуально на август 2026 года. В инструкции используется Ubuntu 26.04 LTS.

Этот вариант подходит студентам, которые готовы установить Linux непосредственно на свой компьютер: вместо текущей операционной системы либо рядом с ней.

## Перед началом

**Установка операционной системы меняет разметку диска и при неправильном выборе может привести к потере данных.**

Перед семинаром или перед началом установки:

1. Сохраните важные файлы на внешний диск или в облако.
2. Подключите ноутбук к зарядке.
3. Подготовьте USB-флешку объёмом не менее 8 ГБ. Данные на ней будут удалены.
4. Если вы не уверены, что готовы менять разметку диска, используйте [виртуальную машину](02_ubuntu_virtualbox.md), [WSL](03_ubuntu_wsl.md) или [SSH-сервер семинариста](04_ssh_server.md).

### Важное замечание для Mac

Эта инструкция рассчитана прежде всего на обычные ПК и ноутбуки с процессорами Intel/AMD. Нативная установка Ubuntu на Mac с Apple Silicon (M1/M2/M3/...) имеет отдельные ограничения и не поддерживается Canonical как обычная установка Ubuntu Desktop. Для такого компьютера на семинаре лучше выбрать виртуальную машину или SSH.

## 1. Скачайте Ubuntu

Откройте официальный сайт:

<https://ubuntu.com/download/desktop>

Скачайте **Ubuntu 26.04 LTS Desktop** для Intel/AMD 64-bit (`amd64`).

## 2. Создайте загрузочную флешку

ISO-файл нельзя просто скопировать на флешку — его нужно записать как загрузочный образ.

Используйте инструкцию Ubuntu:

<https://documentation.ubuntu.com/desktop/en/26.04/tutorial/install-ubuntu-desktop/>

На Windows удобно использовать Rufus. На Linux можно использовать приложение Disks. Перед записью ещё раз убедитесь, что выбрана именно флешка: её содержимое будет уничтожено.

## 3. Загрузитесь с флешки

1. Перезагрузите компьютер.
2. Откройте Boot Menu. Клавиша зависит от производителя и обычно показывается при включении компьютера (`F12`, `F9`, `Esc` и т. п.).
3. Выберите USB-накопитель.
4. Дождитесь запуска установщика Ubuntu.

Если вы сомневаетесь в совместимости оборудования, сначала выберите **Try Ubuntu** и проверьте клавиатуру, Wi-Fi, тачпад и экран. Этот режим не меняет данные на диске.

## 4. Запустите установку

В установщике выберите интерактивную установку и следуйте стандартным шагам: язык, клавиатура, сеть и набор программ.

На этапе выбора диска возможны два основных сценария.

### Вариант A. Ubuntu будет единственной системой

Выберите **Erase disk and install Ubuntu** только если вы действительно хотите удалить содержимое выбранного физического диска.

**На реальном компьютере эта опция удаляет данные с диска.**

### Вариант B. Ubuntu рядом с существующей системой

Если установщик предлагает **Install Ubuntu alongside ...**, этот вариант позволяет сохранить существующую систему и выбирать ОС при загрузке.

Если установщик сообщает о BitLocker, Intel RST, не предлагает установку рядом с существующей системой или вы не уверены в выборе разделов — **не переходите к ручной разметке диска самостоятельно**. Позовите семинариста.

## 5. Создайте пользователя

Можно использовать своё обычное имя пользователя. Для курса важно не конкретное имя, а умение обращаться к домашней директории через `$HOME` и `~`.

Запомните пароль: он потребуется для команд `sudo`.

## 6. После установки

Откройте терминал и выполните:

```bash
sudo apt update
sudo apt upgrade
```

Затем проверьте среду:

```bash
whoami
pwd
uname -a
cat /etc/os-release
```

Установка считается завершённой, если вы вошли в Ubuntu, можете открыть терминал и команды выше выполняются без ошибок.

## Если возникла проблема

Не продолжайте наугад действия с разделами диска. Зафиксируйте текст ошибки или сфотографируйте экран и позовите семинариста.
