# Сдача семинара 7 — Mission Control

Пройдите [семинар «Старт разрешён»](../../Семинар%207.%20CI-CD.md).
Если начали работу на занятии, продолжайте в том же репозитории.

Отправьте семинаристу **одну ссылку на вашу страницу GitHub Pages**.
На панели должны быть ваш позывной из карточки Evil Corp, название
миссии, телеметрия и две рабочие ссылки. Первая ведёт на запуск
публикации с артефактом, вторая — на PR с инцидентом. Ссылки
генерируются при сборке страницы.

## Условия зачёта

- В своём репозитории вы дописали два шага в `verify`. В запуске видны
  отдельные проверки модуля (`make test`) и телеметрии
  (`make check-data`).
- В описании одного PR есть ссылки на красный и зелёный запуски и ваше
  объяснение сбоя. Исправляющий коммит меняет данные и добавляет
  тесты для `19` и `25`.
- Панель показывает ваш позывной. Ссылка с панели на Actions ведёт на
  успешный запуск в `main` после слияния. В нём есть `mission-report`
  и успешное задание `deploy`.

За выполненный сценарий ставится **1**. Перед сдачей запустите
`./check.sh` и откройте обе ссылки на опубликованной панели.
`check.sh` проверяет локальные файлы и сборку. Историю PR и публикацию
проверяют по GitHub.
