# Подготовка к семинару: Ubuntu в WSL

> Актуально на август 2026 года. В качестве Linux-дистрибутива используется Ubuntu.

Этот вариант подходит пользователям Windows 10/11, которые хотят работать с Linux-командной строкой без отдельной виртуальной машины.

Для задач первого семинара WSL подходит практически так же, как обычная Ubuntu. Позднее в курсе некоторые системные детали могут отличаться от полноценной VM, поэтому важно помнить, что вы работаете именно внутри WSL.

## 1. Проверьте версию Windows

Современная команда установки WSL поддерживается в Windows 10 версии 2004 (Build 19041) и новее, а также в Windows 11.

Если у вас старая версия Windows, обратитесь к семинаристу.

## 2. Установите WSL

Откройте **PowerShell** или **Windows Terminal** от имени администратора и выполните:

```powershell
wsl --install
```

После установки перезагрузите компьютер, если Windows попросит это сделать.

Если WSL уже установлен и команда показывает только справку, посмотрите доступные дистрибутивы:

```powershell
wsl --list --online
```

После этого Ubuntu можно установить командой вида:

```powershell
wsl --install -d <имя-дистрибутива-из-списка>
```

Для курса выбирайте Ubuntu LTS.

## 3. Первый запуск Ubuntu

Откройте Ubuntu через меню Start либо выполните в Windows Terminal:

```powershell
wsl
```

При первом запуске Linux-среда закончит установку и попросит создать:

- Linux username;
- Linux password.

Пароль при вводе в Linux обычно **не отображается вообще** — даже звёздочками. Это нормально.

Запомните пароль: он понадобится для `sudo`.

## 4. Проверьте, что используется WSL 2

В PowerShell выполните:

```powershell
wsl --list --verbose
```

У Ubuntu в столбце `VERSION` должно быть `2`.

Если это не так, покажите вывод семинаристу.

## 5. Обновите Ubuntu

Уже **в Linux-терминале**, а не в PowerShell, выполните:

```bash
sudo apt update
sudo apt upgrade
```

## 6. Проверьте Linux-среду

В Linux-терминале выполните:

```bash
whoami
pwd
uname -a
cat /etc/os-release
```

Установка считается завершённой, если эти команды выполняются и `cat /etc/os-release` показывает Ubuntu.

## Где хранить учебные проекты

Для Linux-проектов создавайте рабочие каталоги внутри Linux-домашней директории, например:

```bash
mkdir -p ~/university
cd ~/university
```

Каталог `~` находится в файловой системе WSL. Это предпочтительнее, чем постоянно работать с проектами через `/mnt/c/...`: так меньше различий в правах, производительности и поведении Linux-инструментов.

## Как запускать WSL в следующий раз

Из Windows Terminal:

```powershell
wsl
```

или откройте установленное приложение Ubuntu из меню Start.

Чтобы завершить Linux-shell:

```bash
exit
```

## Если установка не работает

Сохраните вывод команд:

```powershell
wsl --status
wsl --list --verbose
```

и покажите его семинаристу. Не включайте и не отключайте вручную случайные компоненты виртуализации по инструкциям из интернета до разбора причины.
