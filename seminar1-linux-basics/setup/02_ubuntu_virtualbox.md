# Подготовка к семинару: Ubuntu в VirtualBox

> Актуально на август 2026 года. В инструкции используется Oracle VirtualBox 7.2 и Ubuntu 26.04 LTS.

Этот вариант позволяет получить полноценную Linux-систему, не меняя операционную систему и разметку диска основного компьютера.

## Перед началом

Для комфортной работы виртуальной машине нужна часть ресурсов основного компьютера.

Рекомендуется:

- не менее 8 ГБ RAM на основном компьютере; при меньшем объёме лучше использовать WSL или SSH;
- не менее 35 ГБ свободного места на диске;
- аппаратная виртуализация, включённая в BIOS/UEFI (обычно она уже включена).

## 1. Определите архитектуру компьютера

Для большинства компьютеров с Intel или AMD нужна архитектура **amd64/x86_64**.

Для Mac с Apple Silicon (M1/M2/M3/...) нужна архитектура **ARM64**. На ARM-хосте нельзя запускать x86_64-гостя в VirtualBox: скачивайте ARM64-образ Ubuntu.

На Windows-компьютерах с ARM-процессором поддержка VirtualBox остаётся экспериментальной; для семинара предпочтительнее WSL или SSH.

## 2. Установите VirtualBox

Скачайте VirtualBox с официального сайта:

<https://www.virtualbox.org/wiki/Downloads>

Выберите пакет для своей основной ОС и архитектуры:

- Windows hosts;
- macOS / Intel hosts;
- macOS / Apple Silicon hosts;
- Linux distributions.

Установите VirtualBox стандартным способом.

## 3. Скачайте Ubuntu

Откройте:

<https://ubuntu.com/download/desktop>

Скачайте **Ubuntu 26.04 LTS Desktop** подходящей архитектуры:

- Intel/AMD PC → Intel or AMD 64-bit (`amd64`);
- Apple Silicon → ARM 64-bit (`arm64`).

## 4. Создайте виртуальную машину

1. Откройте VirtualBox Manager.
2. Нажмите **New**.
3. Назовите машину, например `Ubuntu-Student`.
4. Укажите скачанный ISO-образ Ubuntu.
5. Для учебного семинара предпочтительнее обычная ручная установка. Если VirtualBox предлагает **Unattended Installation**, можно отключить её (`Skip Unattended Installation`), чтобы дальнейшие шаги совпадали с обычным установщиком Ubuntu.

### Ресурсы виртуальной машины

Ориентируйтесь на возможности основного компьютера:

- RAM: 4 ГБ как рабочий минимум для VM; если на компьютере 16 ГБ RAM и больше, удобно выделить 6 ГБ;
- CPU: 2 виртуальных процессора, но не более половины доступных потоков основного компьютера;
- виртуальный диск: **25 ГБ или больше**, динамически выделяемый.

Не отдавайте виртуальной машине почти всю память или все процессоры: ресурсы нужны и основной системе.

## 5. Установите Ubuntu внутри VM

Запустите созданную виртуальную машину. Должен открыться установщик Ubuntu.

Следуйте стандартным шагам установки. На этапе выбора диска можно выбрать:

**Erase disk and install Ubuntu**.

> В этой инструкции речь идёт о **виртуальном диске созданной VM**, а не о физическом диске вашего компьютера. Эта операция удаляет данные только внутри виртуального диска данной машины.

Создайте пользователя и запомните пароль.

После завершения установки перезагрузите виртуальную машину. Если VirtualBox продолжает загружать установщик, отключите ISO из виртуального CD/DVD-привода и загрузитесь ещё раз.

## 6. Проверьте результат

Откройте терминал в Ubuntu и выполните:

```bash
whoami
pwd
uname -a
cat /etc/os-release
```

Обновите список пакетов:

```bash
sudo apt update
```

Установка считается завершённой, если Ubuntu загружается с виртуального диска и терминал работает.

## Частые проблемы

### В списке нет 64-bit Linux или VM не запускается

Проверьте, включена ли аппаратная виртуализация в BIOS/UEFI. На Windows также возможны конфликты или особенности работы с Hyper-V/VBS — в этом случае покажите ошибку семинаристу, а не меняйте системные настройки наугад.

### На Mac с Apple Silicon ISO не загружается

Проверьте, что вы скачали именно ARM64-образ Ubuntu. x86_64-образ на ARM-хосте VirtualBox не поддерживается.

### VM работает слишком медленно

Закройте тяжёлые программы на host-системе. Если компьютеру не хватает RAM, выберите WSL или SSH вместо VM.
