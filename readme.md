# Введение в операционные системы и инструменты разработчика

В этом репозитории будут публиковаться задания, материалы и дополнительные ресурсы для семинаров по дисциплине **«Введение в операционные системы и инструменты разработчика»**.

## Содержание репозитория

Здесь вы найдёте:

- задания для семинарских занятий;
- инструкции по установке и настройке необходимого ПО;
- примеры команд, программ и конфигураций;
- дополнительные материалы для самостоятельного изучения;
- ссылки на полезную документацию и ресурсы.

## Как начать работу

Сначала склонируйте репозиторий на свой компьютер:

```bash
git clone https://github.com/alexpti4ka/nsu-os-devtools.git
```

Перейдите в созданную папку:

```bash
cd nsu-os-devtools
```

В дальнейшем перед началом работы с материалами обновляйте локальную копию репозитория:

```bash
git pull
```

Команду `git pull` необходимо выполнять из папки `nsu-os-devtools`.

## Как работать с материалами

Перед семинаром ознакомьтесь с материалами соответствующей темы и выполните подготовительные шаги, если они указаны в инструкции. Задания и обновления будут добавляться по мере прохождения курса.

Если вы заметили ошибку или у вас возник вопрос по заданию, создайте Issue в репозитории или обратитесь к преподавателю.
