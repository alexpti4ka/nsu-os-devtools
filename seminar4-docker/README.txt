Seminar 4 workbench
===================

Демо-проекты для практики семинара 4 (Docker). Исходный код менять не требуется —
семантика этих программ не является предметом семинара.

hello/
  main.c            крошечная программа: читает data/input.txt и печатает строку
  Makefile          сборка через make (цели all, hello, clean)
  data/input.txt    входной текстовый файл — его удобно менять в задаче про кэш слоёв
  (Dockerfile студент пишет сам в задаче 4)

load/
  cpuload.c         бесконечный цикл с накоплением — источник CPU-нагрузки
  memload.c         заполняет запрошенный объём памяти и удерживает его
  Dockerfile        образ demo-load для задачи 9
